# Win32-System-Monitor
一个基于 C++ 和 Win32 API 开发的轻量级系统实时监控工具。

## 🚀 功能特性
- **实时监控**：利用 Windows 底层 API 获取毫秒级 CPU 占用率。
- **轻量化**：原生 C++ 编写，无第三方库依赖。
- **跨版本兼容**：支持 Windows 10/11。

## 🛠 开发环境
- **IDE**: Visual Studio 2022
- **语言标准**: C++ 17
- **平台**: x64 (Windows)

## 📦 如何构建
1. 使用 VS2022 打开 `.sln` 解决方案文件。
2. 设置为 `Release | x64` 配置。
3. 点击“生成解决方案”。
4. 在 `/bin` 目录下找到生成的 `.exe` 文件。
